# مختبر فسلجة التنفس

شرح تفاعلي للفصل الثالث من كتاب فسلجة الحيوان النظري: **فسيولوجيا التنفس** (ص 92–112).

**الرابط:** https://ibnsamh97-ai.github.io/frog-heart-lab/respiration/

## المحتوى
- 12 قسماً بنص الكتاب، والمهم مؤشَّر بالأصفر، وأسئلة «علل» بجانب الشرح.
- 3 مجسمات ثلاثية الأبعاد: الرئتان، الأسناخ والشعيرات، جزيئة الهيموكلوبين.
- محاكاة لكل فكرة: الشد السطحي، الشهيق والزفير، جهاز قياس التنفس، معدل التنفس، جدول 3‑2، منحني الافتراق، شكل 3‑8، تأثير بور.
- مراجعة: 20 بطاقة علل، أرقام يجب حفظها، اختبار من 18 سؤالاً، ومصطلحات.
- زر **الخط** في الأعلى للتبديل بين: نسخ، القاهرة، المراعي.

## الملفات
| الملف | ماذا فيه |
|---|---|
| `index.html` | نص الشرح وترتيب الأقسام |
| `css/style.css` | الألوان والخطوط (الوضع الفاتح والداكن) |
| `js/core.js` | أدوات مشتركة، منحني الافتراق، الفهرس، زر الخط |
| `js/viewer3d.js` | المجسمات الثلاثية الأبعاد |
| `js/sims-a.js` | محاكاة الأقسام 1–4 |
| `js/sims-b.js` | محاكاة الأقسام 5–8 |
| `js/sims-c.js` | محاكاة الأقسام 9–12 |
| `js/review.js` | بطاقات علل، الأرقام، الاختبار، المصطلحات |

لإضافة سؤال إلى الاختبار: افتح `js/review.js` وأضف سطراً إلى قائمة `QUIZ` (الجواب الصحيح أول خيار، والموقع يخلط الترتيب).
