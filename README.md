# مختبر قلب الضفدع

محاكاة تفاعلية للجزء العملي من محاضرة «تأثير بعض الأدوية والعقاقير الطبية على النبض النسقي في قلب الضفدع» — فسلجة الحيوان العملي، المرحلة الرابعة.

**رابط التشغيل:** https://ibnsamh97-ai.github.io/frog-heart-lab/

## ماذا تحتوي
- تخدير الضفدع، وتثبيته على لوح التشريح، وتنظيف منطقة الشق بالكحول
- شق الجلد ثم جدار البطن، وقص الحزام الصدري، وإزالة غشاء التامور
- عدّ ضربات القلب لدقيقة واحدة: الحالة الطبيعية، بعد رنكر + أدرينالين، بعد الغسل برنكر، بعد رنكر + أستيل كولين
- مخطط انقباضات، ودفتر مختبر للنتائج، وصفحة نتائج واستنتاج مع شرح السبب

## هيكل الملفات

| الملف | ماذا فيه |
|---|---|
| `index.html` | هيكل الصفحة، وأيقونات الأدوات، والجداول |
| `css/style.css` | الألوان والخطوط والتنسيق (الألوان في أول الملف داخل `:root`) |
| `js/config.js` | القيم التي تعدّلها بسهولة: عدد الضربات، قوة الانقباض، مدة التخدير |
| `js/app.js` | منطق المحاكاة: رسم الضفدع والقلب، الأدوات، خطوات التجربة، العدّ |
| `assets/preview.png` | الصورة التي تظهر عند مشاركة الرابط في واتساب وغيره |

## تعديل القيم
افتح `js/config.js` وغيّر الأرقام ثم احفظ:

```js
rates: {
  base: 70,  // الحالة الطبيعية
  adr: 80,   // بعد رنكر + أدرينالين
  ach: 50    // بعد رنكر + أستيل كولين
}
```

## أين أعدّل النصوص والخطوات
- **أسماء الخطوات وترتيبها:** المصفوفة `STEPS` في `js/app.js`
- **تعليمات كل خطوة والمعلومة أسفلها:** الدالة `renderCard` في `js/app.js`
- **الاستنتاج وشرح السبب:** الدالة `resultsHTML` في `js/app.js`
- **أسماء الأدوات والمحاليل:** الكائن `TOOLS` في `js/app.js`
- **رسم الأعضاء:** الدوال `buildFrogV` و`buildMuscle` و`buildOrgans` في `js/app.js`

## التشغيل على جهازك
افتح `index.html` مباشرة في متصفح Chrome، أو شغّل خادماً محلياً داخل المجلد:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages
1. من صفحة المستودع: **Settings** ← **Pages**
2. في **Source** اختر **Deploy from a branch**
3. اختر الفرع **main** والمجلد **/(root)** ثم **Save**

بعد دقيقة أو دقيقتين يعمل الرابط أعلاه، وكل تعديل ترفعه للمستودع يظهر فيه تلقائياً.
